はじめる前に
LINE側の準備が必要です。個人どうしのトークは読めません（LINEの仕様）。転送元は、Musubot の LINE公式アカウントを招待できるグループである必要があります。

{{ icon.list(17) }} 設定の手順

  1. LINE Developers にログイン → プロバイダーを作成
  2. Messaging API のチャネルを作成（＝LINE公式アカウントができます）
  3. 「チャネル基本設定」の チャネルシークレット を下にコピー
  4. 「Messaging API設定」で チャネルアクセストークン（長期） を発行して下にコピー
  5. 同じ画面の 応答メッセージをオフ、Webhookの利用をオン にする
  6. 下の Webhook URL をコピーして、LINE側の Webhook URL に貼り付け → 「検証」を押す
  7. 転送元のLINEグループに、この公式アカウントを招待する
  8. 下で転送先の Discord チャンネルを選んで保存
