使い方ガイド

Musubot は、Discord サーバーの運営作業（翻訳・問い合わせ対応・抽選・送料計算・画像転送など）を自動化する BOT です。設定はすべてこのダッシュボードから行い、保存すると数秒で Discord 側に反映されます。

{# ================= はじめに ================= #}

{{ icon.rocket(18) }} はじめに — Musubot の全体像と動かし方

Musubot は 「ダッシュボード」と「Discord 上の BOT」の2つでできています。 あなたが操作するのはこのダッシュボードだけで、Discord 側にコマンドを打ち込む必要はほとんどありません。

{{ icon.layers(16) }} ダッシュボード（この画面）
  • どの機能を使うかを ON にする
  • 対象チャンネル・ロールを選ぶ
  • 文面や金額などを編集する
  • BOT の起動 / 停止 / ログ確認
{{ icon.knot(16) }} Discord 上の BOT
  • 設定どおりに自動で動く
  • 翻訳・歓迎・転送は全自動
  • お客様は /shipping 等を使う
  • 設定変更は数秒で自動反映
大事な考え方：「どの機能を使いたいか」はすべてこのダッシュボードで決めます。保存を押すと BOT が自動で再読み込みして Discord に反映されるので、 Discord 側を直接いじる必要はありません。設定を変えたくなったら、いつでもここに戻ってきて保存し直すだけです。

具体的な手順
  1. Discord BOT を作る
    Discord Developer Portal で New Application → 左メニュー Bot → Reset Token でトークンをコピー。 同じ画面で MESSAGE CONTENT INTENT と SERVER MEMBERS INTENT を必ず ON にします。 （詳細な画面つき手順は下の「API設定」にあります）
  2. BOT をサーバーに招待する
    同じポータルの OAuth2 → URL Generator で bot と applications.commands にチェック → 権限は「管理者」または必要権限（メッセージ送信・ファイル添付・チャンネル管理・ロール管理・サーバー管理）を選択 → 生成された URL を開いて、対象サーバーに追加します。
  3. ダッシュボードでサーバーを開く
    ダッシュボード に、あなたが管理者権限を持つサーバーが並びます。設定したいサーバーのタイルをクリックしてください。
  4. API タブにトークンを貼って保存
    まず Discord BOT トークンだけを貼って保存します。これが成功すると、他のタブのチャンネル一覧・ロール一覧が Discord から自動で読み込まれ、プルダウンで選べるようになります。 翻訳を使うなら DeepL キー、意図判定を使うなら Anthropic キーも続けて入れて保存。
  5. 使いたい機能だけ設定する
    上部のタブ（API / 翻訳 / チケット / Welcome / 意図判定 / 送料 / Auction / 招待 / 転送メッセージ）を切り替えて、使う機能だけ設定してください。 使わないタブは空のままで構いません。各タブの右下「変更を保存」で保存します。
  6. BOT を起動して動作確認
    左上のサーバー名の下にある 稼働状況・ログ を開き、起動を押します。「稼働中」になれば OK。 うまく動かないときは、同じページのログに理由が出ています。
日々の使い方
  • 設定を変えたい → サーバー設定の該当タブを直して「変更を保存」。BOT の再起動は不要です。
  • 抽選をやりたい → Giveaway ページで賞品と期間を入れて投稿。当選発表まで全自動です。
  • 調子が悪い → 稼働状況・ログ でログを確認し、必要なら「再起動」。
  • 新しいサーバーを追加したい → 手順1〜6をそのサーバーでもう一度。BOT トークンは同じものを使い回せます。
つまずきやすいポイント
・チャンネル一覧が空 → BOT トークンが未保存、または BOT がそのサーバーに招待されていません
・翻訳・転送が動かない → MESSAGE CONTENT INTENT が OFF になっています
・オンボーディングが使えない → Discord 側でサーバーの「コミュニティ機能」を有効化してください
設定の開き方（共通）
サーバー一覧 → 対象サーバーを開く → 上部のタブを切り替えて設定 → 各タブの「変更を保存」。 転送メッセージだけは追加・編集した瞬間に反映されます。

{{ icon.key(18) }} API設定

Botの動作に必要なキーをまとめて設定します。まず最初にここを設定してください。必要なキーは3つ：① Discord BOTトークン（必須）、② DeepL APIキー（翻訳）、③ Anthropic APIキー（意図判定・翻訳の予備）。

  1. 上記サイトを開き、右上の New Application でアプリ作成（名前は何でもOK）
  2. 左メニューの Bot を開く
  3. Reset Token → 表示されたトークンをコピー（この画面でしか見られないので必ず控える）

MESSAGE CONTENT INTENT がOFFだと、Botがメッセージ本文を読めず翻訳・転送・意図判定が動きません。

{# ================= 各機能 ================= #}

{{ icon.globe(18) }} 翻訳

指定したチャンネルの英語・日本語の発言を、Botが自動で翻訳して返信します（英文→日本語 / 日本文→英語）。

  1. 翻訳対象チャンネルを選択（複数可）。チケットカテゴリ全体を対象にもできます
  2. 翻訳プロバイダ（DeepL推奨）と既定の翻訳方向（双方向/英→日/日→英）を選ぶ → 保存
URL・絵文字のみ・短すぎる文は無視されます。月間予算を超えると自動停止します。

{{ icon.ticket(18) }} チケット

お客様が「Open ticket」ボタンを押すと、本人専用のプライベートチャンネルが自動作成されます。

  1. チケット親カテゴリを選択（新規チケットchがここに作られます）
  2. 運営スタッフロールを選択（このロールの人だけがチケットを閲覧可）→ 保存
  3. 「チケットパネルを投稿」で、ボタン付きパネルを任意チャンネルに設置
1ユーザーにつき1チケットまで。クローズすると5秒後に削除されます。

{{ icon.sparkles(18) }} Welcome

新しい人がサーバーに入った瞬間に、歓迎メッセージを自動投稿します。

  1. Welcome投稿先チャンネルを選択
  2. タイトル・本文・色・バナー画像をカスタマイズ → 保存
  3. 「Welcome を投稿」で自分に見え方を確認できます
招待トラッキングと連動し、「どの招待で入ったか」も同時に表示できます。

{{ icon.sparkles(18) }} 意図判定

監視チャンネルの発言をAIで分類し、商品問合せ・配送相談を検知したら誘導文を返信します。

  1. 監視チャンネルと誘導先（#ticket・/shipping 等）を設定 → 保存
  2. ON にすると自動で動作します
反応は同じメッセージに1回だけ。誘導テキストを送るだけで、チケット作成などの能動アクションはしません。Anthropic APIキーが必要です。

{{ icon.box(18) }} 送料

商品×数量×宛先国から、DHL/FedExの安い方を自動で計算します（Google Sheets連携）。

  1. スプレッドシート／サービスアカウントを設定
  2. 燃油サーチャージの最新値を確認（毎週自動取得）→ 保存
  3. Discordで /shipping を実行するとカート式パネルが起動
商品重量＋梱包材1kg、0.5kg刻み切り上げ。20kg超は自動で分割発送して合算します。

{{ icon.gavel(18) }} Auction

ボタン入札式オークションの既定値を設定します（実行は Discord の /auction create）。

  1. 最低落札価格・最小増分・アンチスナイプ（終了前の自動延長）等の既定値を設定 → 保存
  2. Discordで /auction create で出品
入札は「現最高値＋5%以上 かつ 最小増分以上」。落札時は落札者・Host・Staffだけの取引チャンネルが自動作成されます（決済は人が調整）。

{{ icon.gift(18) }} Giveaway

参加ボタン付きの抽選メッセージを、Discord にコマンドを打たずにダッシュボードから作成・投稿できます。

  1. サーバーを開いて Giveaway ページへ
  2. 賞品名・当選数・期間（30s / 1h / 1d2h）・投稿先チャンネルを入力
  3. 「投稿する」を押すと即座に Discord に投稿されます
期間終了時に BOT が自動で抽選・当選発表まで行います。途中でやめたい場合は「早期終了」。

{{ icon.door(18) }} 招待

入室時にどの招待コードで来たかを自動判定し、Welcome embed と運営ログに記録します。

  1. 判定ログの送信先、/invite create が使えるチャンネル/ロールを設定 → 保存
  2. Discordで /invite list / /invite create
複数Instagramアカウントの流入元判別に使えます。Botに「サーバー管理」権限が必要です。

{{ icon.forward(18) }} 転送メッセージ

監視元チャンネルの画像＋本文を、別チャンネル（別サーバー可）へ自動転送します。

  1. ① 送信元・② 転送先のチャンネルを選ぶ（サーバー→チャンネルの順）
  2. ③ 送り方（モード）を選ぶ: そのまま／画像のみ／加工（原文＋付加文）／任意テキストに置換
  3. ④ 送信者フィルタ（任意）: 指定ロールの人の投稿だけ転送（未選択なら全員）
  4. 「加工」「任意テキストに置換」ではカスタム文を入力。プレビューで転送先の見え方を確認
  5. 「ルールを追加」で作成。既存ルールは「編集」で変更、「削除」で削除（いずれも即反映）
別サーバーへ転送するには、その転送先サーバーにも転送Botが参加している必要があります。トリガーは「画像を含む投稿」です。
